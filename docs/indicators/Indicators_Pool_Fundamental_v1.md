**Valuation-base convention (v1.6, applies wherever a valuation ratio appears in this doc): every value ratio is tagged `(EQ)` or `(EV)`.** **`(EQ)` = equity / stock-level**: the numerator is a claim to *equity holders* and the denominator is **market cap or book equity** (E/P, B/P, dividend yield); these are **capital-structure-*dependent*** (leverage changes them). **`(EV)` = enterprise-value**: the numerator is a claim to *all* capital providers and the denominator is **EV = mcap + total debt + minority interest + preferred − cash** (EBIT/EV, NOPAT/EV, EnterpriseCFO/EV, FCFF/EV, sales/EV, unlevered numerators, §F1); these are **capital-structure-*neutral***. **Never composite an `(EQ)` and an `(EV)` measure without noting the base** (they answer different questions), and never apply either base to financials (EV is meaningless there: §Financials child). The tag travels with the measure so any composite is auditable for base-mixing.

Grades below: per-market **E** (evidence) as in parent files; A-share grades deliberately NOT inherited from US evidence. **Single letters A/B/C/D only (v1.1)**: where specifications within a family differ, grade the specification in the research tracker; no family-level ranges.

## 2. The Seven Families (+ controls & screens)

### F1: Multi-metric Value (core, US **B** · CN **B**)
**Measures, each tagged by denominator base `(EQ)` = equity/stock-level vs `(EV)` = enterprise-value (see the base convention in §1):**
- **`(EQ)` equity/stock-level** (claim to *equity* holders, denominator = market cap or book equity): **E/P** (trailing & forward earnings yield), **B/P** (book-to-price).
- **`(EV)` enterprise-value** (claim to *all* capital providers, denominator = **EV**): **FCFF/EV** (primary enterprise cash yield), **sales/EV**, **EBIT/EV** (enterprise earnings yield), with **EnterpriseCFO/EV, NOPAT/EV, EBITDA/EV as named robustness variants only**: *not* separate votes (see the composite anti-double-count rule in §3; `EnterpriseCFO/EV` and `FCFF/EV` are mechanically nested: `FCFF = EnterpriseCFO − capex`, so only one enters the base composite).
- **EV construction (frozen) + MIXED timing (declare both clocks):** `EV = market cap + total debt (short+long) + minority interest + preferred − cash & equivalents`. **Market cap uses the SIGNAL-DATE price × signal-date shares outstanding; debt/cash/minority/preferred use the latest CAUSALLY-AVAILABLE filing** (as-filed, not restated): the two clocks differ and must be stated. No zero-substitution for a missing component (missing → the `(EV)` measure is NA, never fabricated).
- **⚠ NONPOSITIVE / degenerate EV rule (v1.9):** for very cash-rich firms `EV` can be **≤ 0 or below a declared positive floor**: where `FCFF/EV` and `EBIT/EV` have **no monotonic meaning**. Rule: **`EV ≤ floor` → the EV-based measures are UNAVAILABLE (NA) for that name; keep the `(EQ)` measures (E/P, B/P); report the excluded population separately; NEVER winsorize a negative/tiny denominator into apparent extreme cheapness.**
- **Enterprise-cash-flow INPUT contract (v1.10, every adjustment assigned to EXACTLY ONE location, no double-count):** `EnterpriseCFO = NOPAT + D&A + NC_{ex-D&A} − ΔNOWC`.
  - **`NormalizedEBIT` = reported OPERATING PROFIT / EBIT (pre-financing, pre-tax), with `reported EBIT WITHOUT normalization` retained as a declared ROBUSTNESS baseline** (normalization is a modeling choice, not obviously correct). **The exceptional-item taxonomy is ENUMERATED and signed, not "remove impairments/restructuring" blanket**, because *recurring* restructuring and asset impairments can be genuine operating economics. Remove ONLY items flagged non-recurring in the specific signed fields: **US**: `SpecialItems`/`NonrecurringItems` XBRL tags flagged non-recurring (litigation settlements, one-off disposal gains/losses, discrete impairment events); **keep** recurring impairment/restructuring runs. **CN**: the disclosed **非经常性损益 line items that are *operating*** (the 扣非 disclosure enumerates them; take only the operating ones). **⚠ CN correction: 扣非净利润 itself CANNOT define NormalizedEBIT**: 扣非-NI is *after interest and tax*; use **operating profit (营业利润) minus the operating subset of 非经常性损益**, not 扣非-NI.
  - **`T_op`: a POINT-IN-TIME rate with THREE explicitly-labelled cases (fixes the look-ahead; and it is honestly a proxy, not literally each firm's marginal rate):** **`T_op_exact`**: used where a *causal company-period* effective/statutory rate is observable from the filing (the preferred object; incorporates preferential regimes, e.g. CN 15% high-tech shown eligible, and (where computable) state/local). **`T_op_proxy`**, a **dated federal/market statutory rate**, flagged a proxy (US: the **pre-2018 *graduated* schedule top rate 35%**: explicitly the top marginal, not every firm's exact rate; 21% for years beginning after 2017-12-31 with the blended straddle; CN 25% standard); historically-dated regimes only, never today's rate on past years. **Separate NOL / tax-benefit-realizability rule** (NOT a marginal rate): `T_op = 0` when NormalizedEBIT ≤ 0 is a **conservative tax-benefit-realizability convention**, labelled as such, not a claim about the loss firm's marginal rate.
  - **`NC_{ex-D&A}` = non-cash operating charges EXCLUDING anything already in D&A OR in a working-capital liability** (no double-count): add back **SBC** and non-cash operating expenses **not** captured elsewhere; **subtract** non-cash *gains*; **provision *expense* is add-back ONLY IF the matching Δ operating-provision liability is NOT already inside ΔNOWC** (assign each provision to one place, never both).
  - **`ΔNOWC`, exact signs:** `NOWC = (non-cash operating current ASSETS) − (non-debt operating current LIABILITIES)`; `ΔNOWC = NOWC_t − NOWC_{t−1}`. An *increase* in NOWC is a *use* of cash (subtracted). **Supplier financing reclassified to DEBT in BOTH the opening and closing balances** (consistent, so it doesn't leak into ΔNOWC). Cash/debt/financial items excluded; acquisition-driven jumps and FX excluded; as-filed (restatements ignored).
  - **`capex` = PP&E + capitalized operating intangibles, net of disposals**; capitalized R&D and acquisition-driven PP&E are named variants, not primary.
  - **Missing any required input → the EV cash measure is NA** for that name.
- **⚠ ENTERPRISE-CASH numerator: DETERMINISTIC, build-up-from-operating-income primary (NOT the regime-fragile CFO add-back, v1.8 fix):** the earlier `EnterpriseCFO = CFO + cash interest·(1−T)` is a *reconciliation bridge*, not the primary, it is **unsafe across reporting regimes** (it double-adds interest when interest is already classified *outside* operating CF). **Primary construction (regime-independent, built from operating income before financing):**
  `NOPAT = NormalizedEBIT·(1 − T_op)`, `FCFF = EnterpriseCFO − capex` (standard FCFF; taxes on operating income *before* financing effects (Damodaran). **The ONE authoritative `EnterpriseCFO` equation is the input contract below) `EnterpriseCFO = NOPAT + D&A + NC_{ex-D&A} − ΔNOWC`; do NOT code any "+ other non-cash charges" form (it double-counts amortization/provisions).**
  **`T_op` is a normalized operating rate, NOT the observed cash-tax rate** (cash-tax includes financing shields, settlements, loss-carryforwards, one-offs). See the PIT company-period rule in the input contract below.
  **The statement-of-cash-flow bridge stays ONLY as a reconciliation, with a dated interest-classification rule:** **US GAAP**: interest paid is *in* operating CF → add back after-tax, then normalize taxes to the unlevered basis; **IFRS**: **IAS 7** historically permitted interest in operating *or* financing (read the classification; add back **only if** in operating), and **IFRS 18 (effective annual periods from 2027-01-01)** generally moves interest paid to *financing* for **"entities without specified main business activities"** (the standard's precise term, not simply "non-financial companies") → **do not add it back post-IFRS-18**; **Chinese ASBE**: interest paid is a *financing-activity* line (already outside operating CF) → **do not add it back**. In every regime, normalize taxes to the unlevered operating basis. `(EQ)` cash yields (CFO/price) keep the levered numerator by construction, a separate, declared object.
Composite of equity + enterprise measures, sector-relative; no zero-substitution for missing denominators. **Financials are excluded from ALL these industrial formulas (EV is meaningless when debt *is* the business) their sector-native contracts live in `Indicators_Pool_Financials_v1.md` (v1.13); do NOT apply equity-only value + generic quality to them.**
- **Why the `(EV)` earnings yield is not redundant with `(EQ)` E/P (the reason EBIT/EV was added):** **E/P is capital-structure-*dependent***: two firms with identical operations but different leverage get different E/P, whereas **EBIT/EV and NOPAT/EV are capital-structure-*neutral*** (they price the whole enterprise, so leverage cancels). That is a genuinely different value signal (Greenblatt/quality-value), not a re-vote. **BUT apply the anti-zoo/redundancy discipline:** EBIT/EV overlaps E/P and **FCFF/EV** materially, so it enters the `VALUE` composite (§3) **only after an incremental-value ablation against them**: it is one measure inside `VALUE`, never a new factor family.
- **CN:** E/P > B/P per [Liu–Stambaugh–Yuan](https://www.nber.org/papers/w24458); in China use **扣非 E/P** (recurring earnings, §6) as the primary variant, reported NI is contaminated by one-off 保壳 items.
- Failure regime: long value droughts; value trap = cheap + junk (must be crossed with F2/F3/F4).
- **E/P–ROE redundancy rule (v1.1, do not violate):** under identity-consistent E, B, M, `E/P = (B/M) × ROE` (book cancels). Raw E/P, B/M and ROE are therefore **not three independent votes**, and **`B/M × ROE` is classified as E/P. Never a separate value-quality factor.** Value and quality combine as *separate standardized scores or conditional sorts* (§3), not by multiplying B/M by a profitability ratio (the product loses the ROE dimension: a high-ROE franchise and a distressed deep-value name with the same E/P rank identically, and the product does **not** neutralize ROE's leverage problem, you just recover earnings yield). Note this identity is **deliberately broken in the CN pool** because F1 uses 扣非 E/P while F2's ROE may use reported NI, so never treat 扣非 E/P and reported-ROE as mechanically linked. Residual-income view: `P/B = (ROE − g)/(r − g)`, so ROE creates value only when it exceeds `r` and is sustainable, neither E/P nor B/M×ROE identifies `r` without growth/investment/persistence info ([Campbell](https://www.nber.org/papers/w13423), [Frankel–Lee](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6528), [Penman–Reggiani](https://business.columbia.edu/faculty/research/fundamentals-value-vs-growth-investing-and-explanation-value-trap)).

### F2: Profitability (core, US **A** · CN **B**, not auto-transferred)
Measures: gross profit/assets (Novy-Marx), operating profitability, ROA, ROE, ROIC, cash-based operating profitability. **Redundancy-test before compositing, these overlap heavily.**
- **ROE is leverage-contaminated:** pair with ROA/ROIC or DuPont-decompose (margin × turnover × leverage). High-ROE/high-debt ≠ quality.
- **`RNOA` / `CashRNOA` (v1.7; QEPM `RNOA`; `CashRNOA` is a *QEPM-style cash-operating-return proxy*, NOT HOLT `CFROI`, which is a proprietary inflation-adjusted economic-return/IRR framework, do not equate them), operating-return measures that strip *conventional financing* leverage (NOT fully "leverage-free": operating liabilities and leases still lever RNOA, Nissim–Penman):** `NOA = operating assets − operating liabilities`; **`RNOA = NOPAT / avg NOA`** and **`CashRNOA = EnterpriseCFO / avg NOA`** (both use the F1 unlevered NOPAT-build-up numerators). **Maturity: registered robustness variant, the NOA field contract below is a declared checklist, not yet fully fixed** (goodwill / DTA-DTL / denominator-floor treatments are to be declared at spec time).
  - **NOA field contract (declare each, these move the number materially):** exclude **excess cash & marketable securities** from operating assets (they're financial); **goodwill & acquired intangibles**: declare include-vs-exclude (an acquisition-inflated NOA depresses RNOA); **capitalize operating leases** into NOA (post-ASC 842 / IFRS 16 mostly on-balance-sheet. Verify); **net deferred-tax assets/liabilities, pensions, minority interests**: declared operating-vs-financial classification; **industry-normalize** (asset intensity differs by sector); **denominator floor** on |avg NOA|.
  - **Negative/near-zero NOA is NOT auto-NA**: negative operating working capital is *economically normal* for retailers/distributors/platforms (they finance on suppliers/customers). **Report the negative-NOA state as its own flag and use sector-specific eligibility** (drop only where NOA≈0 makes the ratio meaningless), rather than treating all negative NOA as unusable.
  - **ROLE, declared decision rule (not "one of the two enters"):** RNOA/CashRNOA are **registered robustness variants by default**; each **REPLACES its counterpart in the base quality composite (RNOA↔ROIC, CashRNOA↔cash-profitability) IFF it clears an incremental-OOS ablation** against it, otherwise it stays a registered variant *outside* the base mean. Never additive with the measure it would replace.
- **CN:** profitability evidence more consistent than investment ([China FF5 evidence](https://www.sciencedirect.com/science/article/abs/pii/S0927538X17300744), [cash-profitability study](https://www.sciencedirect.com/science/article/pii/S0927538X19306870)). **扣非 scoping (v1.1): the recurring-profit adjustment applies only to NI-based measures (E/P, ROE, net-ROA, SUE); gross, operating and cash profitability keep their native numerators: 扣非净利润 cannot be the numerator of GP/assets or ROIC.**
- **Cash-vs-accrual profitability is MARKET-SPECIFIC (keep the ablation, don't hard-code a winner):** US evidence, cash-based operating profitability is strong and can subsume conventional accruals (Ball et al.); CN evidence, ordinary operating profitability can subsume *cash* profitability. So the cash-vs-operating primary is decided by per-market ablation, not assumed.
- **Operating-liability leverage `OL` / `ΔOL` (QEPM `OL`/`OLinc`), RESEARCH-ONLY CONDITIONAL, NOT a monotonic quality vote:** `OL = operating liabilities / NOA`. The book reads high/rising OL as cheap supplier/customer financing (bargaining power; Nissim–Penman separate operating from financial leverage), **but the sign is NOT universally positive**: high payables can signal supplier power *or* buyer distress; rising customer advances can mean demand strength *or* future delivery obligations; and OL *mechanically* levers RNOA. **Therefore: do NOT add raw OL/ΔOL as alpha.** Test it only as a **conditioner of RNOA/CashRNOA** (does cheap operating financing make a given operating return more/less persistent?), with the working-capital components split out and **industry-normalized** (payment terms differ by sector).
- **`PROFIT_GROWTH` subfamily (F2b, v1.4; US E:B · CN E:C):** realized fundamental-improvement mechanism, distinct from (a) F5 `EARN_EVENT` expectations/revisions and (b) F6 `EXPECTED_INVESTMENT_GROWTH`/q5. All measures **`+` sign** (improvement → higher returns), **year-over-year (t vs t−4q) TTM to remove seasonality**, each with its **own denominator** (the blanket "beginning assets/equity" was wrong):

  | Measure | Exact form (TTM numerators) |
  |---|---|
  | ΔROA | `NI_TTM,t / avgAssets_t − NI_TTM,t-4q / avgAssets_t-4q` (avg = (begin+end)/2) |
  | ΔROE | `NI_TTM,t / avgEquity_t − NI_TTM,t-4q / avgEquity_t-4q`; **CN: replace NI with 扣非净利润** |
  | Δgross-margin | `GrossProfit_TTM,t / Sales_TTM,t − (…)_{t-4q}` |
  | Δoper-margin | `OpProfit_TTM,t / Sales_TTM,t − (…)_{t-4q}` |
  | Δ cash op. profitability | `CashOpProfit_TTM,t / avgAssets_t − (…)_{t-4q}`, where CashOpProfit = operating profit − accruals (Ball et al. cash-based) |

  **"Margin acceleration" disambiguated:** Δmargin (first difference, the *improvement*) is primary; Δ²margin (second difference, is the improvement itself accelerating) is a separate, noisier variant, not the default. Publication lag = as-filed report date (never fiscal-period date). **The realized ΔROE lives here; F5 carries only the *expectations* read (forecast-ROE revision): the same raw ΔROE must not enter F2b, F5 and q5.** Ablate against F2 level profitability before standalone inclusion.

### F3: Earnings/Cash Quality (core component, standalone US **B (decayed)** · CN **C**)
Primary continuous measures (v1.1): accruals = −(NI−CFO)/avg assets and CFO/assets. **CFO/NI is unstable near NI≈0 (explodes or flips sign): compute only for materially positive NI, else mark unavailable**. negative-NI names route to F4/F8 distress flags; FCF conversion under the same rule.
- US standalone accrual anomaly decayed post-publication ([Green et al.](https://pubsonline.informs.org/doi/10.1287/mnsc.1110.1320)) → quality *component*, not isolated alpha; test incremental value over F2.
- **CN:** operating profitability may subsume accrual information. Test F2/F3/cash-profitability separately before combining. Screen role (avoid worst decile) likely > symmetric alpha role.

### F4: Financial Strength (core, US **B** · CN **B**)
Measures: net debt/EBITDA, interest coverage, debt/assets, current ratio, plus structural distress candidates (v1.1 placement): **Altman-Z / Ohlson-O as diagnostics only**: they mechanically overlap profitability, leverage, size and valuation, so never additive with F2/F4 scores; **distance-to-default belongs to a hybrid market/fundamental risk overlay** (it uses market equity and volatility, not pure accounting).
- **CN additions (my pass):** 有息负债率, **大存大贷 flag** (simultaneously high cash + high interest-bearing debt, the Kangmei/Kangde-Xin fraud fingerprint), audited-cash verification proxies. These sit at the F4/F8 boundary.

### F5: Fundamental / Event Momentum (core, US **A** with documented decay · CN **C** until PIT-consensus audit passes; RG `EARN_EVENT`)
Measures: SUE, **earnings-announcement CAR/ABR (v1.2)**, EPS/sales/CFO revision ratio & magnitude (dispersion-scaled), revision breadth, **revision in *forecast* ROE / Δ consensus-expected ROE (expectation-based, v1.4; realized ΔROE lives in F2b, not here)**, forecast-margin revisions, recommendation/price-target changes (recency-weighted per [MSCI Analyst Sentiment](https://www.msci.com/documents/10199/a925c038-cf5e-9701-fe7a-e4414a06b1ca)).
- **Earnings-announcement CAR/ABR (v1.2, from Daniel–Hirshleifer–Sun 2020):** primary = market-adjusted `CAR = Σ_{τ=-2}^{+1}(r_i − r_m)` around the announcement (4 trading days; simple market-adjusted, **not** a beta-estimated residual, that name is also *ABR*; do not make CAR and ABR two indicators). CAR measures the market's *initial interpretation* of the whole announcement; **PEAD is the subsequent drift** (the tradable part). Robustness variants (pre-register, don't select ex-post): industry-adjusted and beta-adjusted CAR. Availability: tradable only after the `+1` return exists → earliest entry next feasible session (the `[-2,-1]` leg is leakage/anticipation, **not** tradable post-publication). Targets 5/21/63d; DHS's ≤6-month-latest-announcement state = robustness spec, short horizons primary. Portfolio: sector/size-controlled ranks; long-only CN can overweight positive-CAR, avoid strongly negative-CAR.
- **Four MECHANISM sub-IDs, one RG. Split by mechanism, but each still needs a declared PRIMARY + vendor/PIT contract before it is a one-formula/one-target row (naming the ID is not yet contracting it)** ([Chan–Jegadeesh–Lakonishok](https://www.nber.org/papers/w5375)): **`F5-SUE`**, accounting result vs expectation; **open choice: seasonal-random-walk vs analyst-consensus expectation** (declare one primary); **`F5-CAR`**: market's read of the entire announcement (contaminated by simultaneous news); **`F5-REV`**: analyst estimate revisions; **DECLARED PRIMARY (v1.8): standardized EPS-revision *magnitude* over a fixed 3-month window** (breadth = robustness estimator, not a second vote. See the frozen sub-contract below); sales/CFO/ROE/margin estimates are named robustness variants; **`F5-RECO`**: recommendation vs price-target changes (declare which primary). **Each requires a declared vendor + PIT contract** (provider, min analysts, vintage timestamp, staleness, revision-as-of), like FIN-B1, not interchangeable, never pooled into one "event score." Keep all, redundancy-test within the RG.
- **`F5-REV` magnitude vs breadth: PRIMARY + STRUCTURAL rules frozen; vendor/PIT + numeric field contract still OPEN (not "fully frozen"):** **magnitude (primary)** = standardized consensus-EPS revision `Δconsensus / dispersion`; **breadth (robustness)** = `(N_up − N_down)/N_eligible-analysts`. Compared on the SAME vendor snapshots, FY-roll rule, eligibility filter and decision cutoff. **Structural rules frozen:** (i) **matched-analyst universe at BOTH endpoints** (only analysts present at start *and* end count → not a composition artifact); (ii) **unchanged = 0, withdrawn/stale = dropped**; (iii) **ONE fixed revision window = 3 months** (source-style 9-month = named variant, not interchangeable); (iv) magnitude and breadth never both enter as independent votes. **Still OPEN (the numeric/vendor field contract, to declare at spec time):** which endpoint's dispersion (start vs current); the **numeric `ε`**; the **analyst minimum** `N_min`; the exact **staleness window** (days); consensus **aggregator (mean vs median)**: declare one; the **FY1/FY2 roll rule**; and whether **`N_eligible`** = all covering analysts or only matched-valid analysts. **Dispersion floor needs BOTH a relative AND an absolute term** (`max(dispersion, ε·|consensus|, δ_abs)`): else when consensus *and* dispersion are both ≈ 0 the relative floor also collapses; a price-scaled alternative (`Δconsensus / |price|`) is the named fallback.
- **`F5-LTG` long-term-growth revision (QEPM `ltgRev9`): DEFERRED research catalogue item, NOT in the operational registry** (no Combination row / active status; it is listed here as a research hypothesis only, and must be *formally registered* (ID/status/RG/cadence/target/sign/promotion-test) before it can ever size anything). **Sign is NOT automatically positive** (two competing effects): **`ΔLTG`** = revision *direction* (may continue) vs **`LTG-level`** (high long-term-growth expectations are prone to over-optimism and predict *lower* returns: La Porta; long-vs-short forecast disparity). **Frozen research spec: preserve BOTH main effects and the interaction**: `Return ~ β₁·ΔLTG + β₂·LTG-level + β₃·(ΔLTG × LTG-level)`: a bare product term would confound "high-and-rising" with "low-and-falling", so main effects are mandatory. **A-share caveat:** LTG analyst history is sparse and often not PIT, grade E:D / R:D, deferred until an audited PIT LTG feed exists.
- **PEAD/FIN factor *betas* are risk-attribution, not stock-ranking inputs (v1.2):** DHS find the event *characteristics* forecast firm returns while estimated PEAD-factor beta does not add firm-level power. Characteristics → alpha; betas → factor-risk attribution only.
- Keep separate from F3: revisions = expectations/momentum; accruals = reliability of what was reported.
- Overlaps price momentum in US; **in CN price momentum is weak/reversal-prone at monthly horizon, so fundamental momentum is the primary expectations carrier, overlap with price momentum lower than US (hypothesis, test).**
- **CN event ladder (v1.1): `预告 → 预告修正 → 快报 → 正式报告 → 重述`, with field-level availability, each field is released to the backtest only at the event that actually disclosed it** (a 预告 profit range reveals no cash-flow, balance-sheet or detailed profitability data). Use a **broad-market primary benchmark with board/industry-adjusted CAR as robustness** (STAR/ChiNext vs Mainboard beta differences contaminate raw market-adjusted CAR). **Price limits & suspensions can make a strong-CAR name untradeable, model entry feasibility after `+1`.** A-share evidence: SUE and announcement abnormal returns are among the few momentum variables surviving conservative Mainboard breakpoints + value weighting, while raw price momentum is weak ([RDQ A-share replication](https://ira.lib.polyu.edu.hk/bitstream/10397/115240/1/Li_Replicating_Digesting_Anomalies.pdf)): hence F5-CN evidence grade stays reasonably positive even as data-readiness stays weak pending the PIT announcement audit.

  - **Source-faithful baseline, exact Hou–Mo–Xue–Zhang (2020, §3.1) definitions** ([q5 RF](https://global-q.org/uploads/1/2/2/6/122679606/houmoxuezhang2020rf.pdf)): **investment-to-assets** `(I/A)_t = (AT_t − AT_{t−1})/AT_{t−1}` (total-asset growth); the **predicted response** is its change `d₁I/A = (I/A)_{t+1} − (I/A)_t`; predictors = **Tobin's `q`**, the paper's **specifically-constructed operating cash flow `Cop`** (NOT an unspecified CFO/assets), and **`dROE`**; predictors & dependent winsorized 1%/99%; **monthly cross-sectional WLS weighted by market equity**. **Freeze the paper's component missing-value rules** (`Cop` build-up and `dROE` fallbacks) exactly, a simple `q/CFO/ΔROE` ranked composite is a *separately named approximation*, not this.

Primary = **monthly rebalance + 1-month return**; 6/12-month overlapping holds = decay variants.
  - *(A full-sample-coefficient version would be a **separate** diagnostic, it is NOT how the published baseline is constructed, so do not present it as a possible reading of the source.)*
  - A simple ranked `q / CFO / ΔROE` composite is a **separately named approximation**, NOT "source-faithful q5."
  - **CN grade E:D / unverified**. realized-investment evidence does not establish expected-growth evidence; hold at unverified research until a source-faithful China replication is identified.
  - Keep distinct from `PROFIT_GROWTH` (F2b) and practitioner "growth style" (analyst LTG + historical EPS/sales growth → exposure/diagnostic first, not automatic alpha, [MSCI Growth](https://www.msci.com/indexes/documents/methodology/2_MSCI_Growth_Target_Indexes_Methodology_20231120.pdf)).

- **Regime dating (my pass, missing from review): the 2024 "国九条"/delisting-and-dividend reform changed this family's distribution: ST warnings for insufficient dividends (no delisting), buybacks-via-bid counted as cash dividends, record 2.2trn RMB payouts, 市值管理 pressure on SOEs ([SSE/CSRC](https://english.sse.com.cn/news/newsrelease/voice/c/c_20240418_10753470.shtml), [China Daily](https://www.chinadaily.com.cn/a/202404/17/WS661f42f8a31082fc043c274f.html)). ### Contextual accounting composites: F-Score and G-Score (v1.3; overlays, **not F9**)

These scores answer a conditional question: **which accounting attributes are useful given the valuation context?** Piotroski's F-Score was designed for financially weak-looking **high-B/M value stocks**; Mohanram's G-Score was designed for difficult-to-value **low-B/M growth stocks**. They reuse F2/F3/F4/F6/F7 and the intangibles overlay, so they are alternative packaging/portfolio-construction specifications. Never extra additive votes beside their own components.

**Piotroski (2000) F-Score, source-faithful annual definition (`0…9`):** use as-reported annual data available at the rebalance date; each condition contributes one point.

| Pillar | Point if… | Existing-family overlap |
|---|---|---|
| Profitability `F_ROA` | `ROA_t = NI_before_XO,t / Assets_{t-1} > 0` | F2 |
| Cash profitability `F_CFO` | `CFO_t / Assets_{t-1} > 0` | F2/F3 |
| Change in profitability `F_ΔROA` | `ROA_t − ROA_{t-1} > 0` | F2b (realized profit growth; v1.4: was mis-mapped to F5) |
| Accrual quality `F_ACCRUAL` | `CFO_t / Assets_{t-1} > ROA_t` | F3 |
| Leverage `F_ΔLEVER` | long-term-debt/average-assets ratio decreased | F4 |
| Liquidity `F_ΔLIQUID` | current ratio increased | F4 |
| External financing `F_EQ_OFFER` | no common-equity issuance during the prior fiscal year | F7/CAPALLOC |
| Operating efficiency `F_ΔMARGIN` | gross margin increased | F2 |
| Operating efficiency `F_ΔTURN` | sales/beginning-assets turnover increased | F2/F6 |

Original population/rule: first restrict to the highest B/M quintile; compare **high F-Score 8–9** with **low 0–1**. The broad `7–9 / 4–6 / 0–3` buckets below belong to Piotroski–So (2012), not the 2000 portfolio definition. The binary design is interpretable and robust to outliers, but discards magnitude; retain a pre-registered continuous/ranked component version as a robustness test, not as a tuned replacement. The original 1976–1996 study reported roughly **7.5 percentage points** higher annual returns for strong high-B/M firms and about **23 percentage points** for high-minus-low F-Score; gains were concentrated in smaller, low-turnover, low-coverage firms. These are historical gross results, not deployable expected returns ([Piotroski 2000](https://www.rentables.fr/wp-content/uploads/2011/01/Piotroski_Value-Investing.pdf)).

**Mohanram (2005) G-Score, source-faithful annual definition (`0…8`):** form contemporaneous two-digit-SIC medians **within the low-B/M universe**; each condition contributes one point.

| Pillar | Point if… | Existing-family overlap |
|---|---|---|
| Profitability `G1` | ROA exceeds the low-B/M industry median | F2 |
| Cash profitability `G2` | CFO/assets exceeds the low-B/M industry median | F2/F3 |
| Accrual quality `G3` | CFO/assets exceeds ROA | F3 |
| Earnings predictability `G4` | **past-5-year ROA variance (3-year minimum)** below the low-B/M industry median: the reproduced Mohanram convention, not an unfrozen "3–5y" choice | Stability |
| Growth predictability `G5` | **past-5-year annual-sales-growth variance (3-year minimum)** below the low-B/M industry median | Stability |
| R&D intensity `G6` | R&D/beginning assets exceeds the low-B/M industry median | Intangibles/F6 |
| Capital intensity `G7` | capex/beginning assets exceeds the low-B/M industry median | F6 |
| Advertising intensity `G8` | advertising/beginning assets exceeds the low-B/M industry median | Intangibles |

Original population/rule: first restrict to the lowest B/M quintile (the source sample allowed negative B/M); compare **high G-Score 6–8** with **low 0–1**. For 1979–1999, the paper reported a **21.2 percentage-point** year-one size-adjusted high-minus-low spread, but most came from the low-score group's −17.9%, while the high group earned +3.3%; it therefore looks especially useful as an **avoid/short screen**. G7 was weak initially and G8 weak later, but were retained to avoid ex-post selection ([Mohanram 2005](https://business.columbia.edu/sites/default/files-efs/pubfiles/1507/mohanram.pdf)). Do not silently assume that high investment is good: G7 directly conflicts with F6's investment/asset-growth hypothesis and advances only inside the low-B/M growth context after an incremental test.

### 3.1 Piotroski–So (2012) expectation-error matrix (v1.3)

**Idea:** B/M is used as a proxy for the performance expectations embedded in price, while F-Score describes recent fundamental strength. Expected returns should be most unusual when the two are incongruent, not whenever B/M is high. This is a two-dimensional conditional sort, not a product of raw variables and not proof that B/M measures mispricing rather than risk.

Source-faithful annual groups: **low B/M / glamour < 30th percentile; middle 30th–70th; high B/M / value > 70th**. F-Score groups are **low 0–3; middle 4–6; high 7–9**. Keep these cutoffs fixed for the primary replication; sector-relative B/M, E/P, C/P and composite-value definitions are named robustness variants.

| F-Score \ B/M | Low B/M: optimistic price expectations | Middle B/M | High B/M: pessimistic price expectations |
|---|---|---|---|
| **High F: 7–9** | **Congruent strength**; no expectation-error trade by itself | mild positive incongruence; research cell | **Extreme positive incongruence → primary long/overweight candidate** |
| **Middle F: 4–6** | mild negative incongruence; research cell | neutral | mild positive incongruence; research cell |
| **Low F: 0–3** | **Extreme negative incongruence → primary short/avoid candidate** | mild negative incongruence; research cell | **Congruent weakness/value trap**; cheapness alone is not a buy signal |

The paper's primary **incongruent** spread (long high-F value, short low-F glamour) earned reported one-year size-adjusted returns of `8.26% − (−14.38%) = 22.64%`, and was positive in 35 of 39 years. By contrast, the **congruent** value-minus-glamour comparison (low-F value minus high-F glamour) was about 0.14% and insignificant. Earnings-announcement returns, analyst forecast errors and forecast revisions moved in the predicted directions, supporting (but not proving) the expectation-error mechanism; SUE and alternative value proxies gave similar conclusions ([Piotroski–So 2012](https://eso.scripts.mit.edu/docs/Identifying-Expectation-Errors.pdf), [RFS abstract](https://academic.oup.com/rfs/article-abstract/25/9/2841/1589567)).

For implementation, preserve the matrix. An optional compact monitor is the following **derived diagnostic, not a formula from the paper**:

`q_BM ∈ {−1,0,+1}` for low/middle/high B/M; `q_F ∈ {−1,0,+1}` for low/middle/high F-Score; `EE = q_BM + q_F`.

Thus `EE=+2` is high-B/M/high-F (positive incongruence), `EE=−2` low-B/M/low-F (negative incongruence), and the congruent corner pairs both score zero. The ±1 cells are exploratory; do not assume monotonicity. A continuous `z(B/M)+z(FundamentalStrength)` version may be tested only after the exact 3×3 replication and must not replace it ex post.

**Portfolio and falsification contract:**

- **US:** academic long-short replication first; production candidate can overweight `+2` and exclude/underweight `−2`. Report each of the nine cells, both corner spreads, EW/VW, industry/size/beta exposures, costs, delistings and capacity, never only the best diagonal.
- **A-share:** F-Score CN grade **C** and single-name shorting is not generally implementable; use `−2` as an avoid/underweight screen and `+2` as an overweight candidate. Test annual source-faithful F-Score separately from the Jiang–Jin–Tang quarterly adaptation. Direct transfer of the US B/M mechanism is unproven; local work has found stronger F-Score effects after high-sentiment periods and on the weak-firm side.

**Idiosyncratic-risk interaction (cross-ref `Indicators_Pool_StatRisk_v1.md`):** high IVOL/MAX/skew should *strengthen* the avoid/underweight signal in the `−2` cell (overpriced + weak, hardest to arbitrage: Stambaugh–Yu–Yuan), and should **not** auto-reject `+2` names merely for elevated IVOL. Pre-registered interaction `LOTTERY_penalty = LOTTERY_score × I(negative expectation error)`, further interacted with aggregate sentiment, tested in the statistical-risk child, not added here as a separate vote.
- **Timing:** reproduce the paper's four-month post-FYE convention, then run exact-disclosure calendar-time cohorts and a six-month/June-30 robustness lag. A return window that begins before all nine inputs were public is rejected. This directly addresses the published implementability critique that conventional return accumulation can assign portfolios before data were known ([Kim–Lee 2014](https://ideas.repec.org/a/taf/euract/v23y2014i4p553-558.html)).
- **Mechanism tests:** next-period announcement CAR, analyst forecast error/revisions, SUE, and future ΔROA/profitability must line up with the sign of `EE`; otherwise call it a return sort, not an identified expectation error. Because B/M also reflects discount rates and accounting measurement, control for beta, size, investment, profitability, leverage and intangible intensity.
- **State dependence:** pre-register interaction (not re-optimization) with the parent Baker–Wurgler sentiment sleeve. Piotroski–So found the incongruent spread larger in high-sentiment states while the congruent spread was unrelated. Also report results across the parent All-Weather growth/inflation environments: recent evidence shows aggregate F-Score is macro-sensitive, especially in contractions ([Anderson–Chowdhury–Uddin](https://link.springer.com/article/10.1007/s11156-024-01331-y)). These are conditioning/attribution tests, never inputs retrofitted after seeing returns.
- **External validity:** European evidence likewise finds value–growth returns concentrated in expectation-error portfolios and absent in congruent portfolios, with persistence beyond one year; this supports a non-US replication but does not establish A-share portability ([Walkshäusl 2017](https://ideas.repec.org/a/oup/revfin/v21y2017i2p845-870..html)).
- **Robustness expectation:** assume published returns shrink. Broad anomaly evidence finds post-publication decay and many signals fail conservative VW/large-cap replications ([McLean–Pontiff 2016](https://onlinelibrary.wiley.com/doi/10.1111/jofi.12365), [Hou–Xue–Zhang 2020](https://www.nber.org/papers/w23394)). The gate is incremental net performance versus F1+F2, not reproduction of a headline gross spread.

Initial production structure (v1.4, consistent with the stated evidence: F3/F4 have screen-grade evidence, so they enter one-sided):


**Reference specification (S&P-QVM style, not a product):**
**Value is built as SEPARATELY-NAMED coverage-homogeneous portfolios, combined at the ALLOCATION level (v1.10, eliminates composition drift; a firm is never silently ranked on a different member-set than its peers):**
- **`ValueEQ` = `mean[z(E/P), z(B/P)]`** built on the **complete-coverage EQ subset** (both present); **`ValueEV` = `mean[z(FCFF/EV){, z(EBIT/EV) if it PASSED its §F1 ablation}]`** on the **complete-coverage EV subset** (the braces make EBIT/EV **visibly conditional**, not a default); **`ValueBoth`** = the combined score on names with full EQ+EV coverage.
- Each is its **own ranked sleeve with a coverage flag**; they are **combined at the allocation level** (Combination), NOT by a per-name renormalized mean, so no firm is ranked on "whatever happens to be present." **Nonpositive-EV / EV-missing cash-rich firms stay in `ValueEQ`** (they are *not* deleted from the value universe, only from `ValueEV`).
- **ONE enterprise cash yield in `ValueEV`: `FCFF/EV` primary** (`EnterpriseCFO/EV`/`EBITDA/EV`/`NOPAT/EV`/`sales/EV` are robustness variants OUTSIDE it, since `FCFF = EnterpriseCFO − capex` nests them and capex is F6's). Enterprise-cash numerators = the *unlevered* NOPAT-build-up (§F1), never raw CFO.
*(Frozen-neutral-imputation and require-complete-coverage-on-one-composite are the two named alternatives, rejected as default because they respectively fabricate data or delete cash-rich firms.)* · `Quality = mean[z(GP/A), z(ROIC), z(CashProfitability), z(Stability)]` · `VQ = 0.5·Value + 0.5·Quality`, with F3/F4/F8a–e as one-sided penalties. ## 6. A-share data contract (the review's biggest blind spot)

1. **Field-level event ladder (v1.1):** `预告 → 预告修正 → 快报 → 正式报告 → 重述`. **Each field is released to the backtest only at the event that actually disclosed it**: a 预告 is typically a profit *range* only (no cash-flow/balance-sheet detail); a 快报 carries a larger accounting set; full statements arrive with the report. 预告 obligations are **trigger-dependent with exemptions** under current [SSE](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/mainipo/c/c_20260424_10816589.shtml)/[SZSE](https://docs.static.szse.cn/www/lawrules/rule/stock/W020260424747613955674.pdf) listing rules, so *"first publication is usually the 预告" is an empirical coverage statement to be measured per period, not an assumption.* PIT joins and PEAD windows key off the actual first-disclosure event per field.
2. **Reporting calendar & clustering:** uniform Dec-31 fiscal year; annual + Q1 both due Apr 30 (double refresh in one week), H1 Aug 31, Q3 Oct 31; releases cluster at deadlines, join on exact publication date; late filing is itself an F8 flag.
3. **扣非净利润 (recurring profit)** is the default earnings numerator (F1/F2/F5): reported NI carries subsidies, asset-sale gains and other 保壳 one-offs, especially near loss/ST thresholds.
4. **Vendor reality:** Tushare/Wind store *latest* restated figures by default, request/keep as-filed report-type flags and snapshot going forward; consolidated vs parent statements must be pinned (consolidated default).
5. **Analyst data reality:** coverage skewed to large caps (revisions usable roughly for the covered top half of mcap), systematic optimism, near-zero sell ratings → use *revisions and dispersion*, not levels; audit 朝阳永续/Wind consensus for point-in-time integrity before F5-CN goes live.
6. **Regime breaks for fundamentals:** 2018 goodwill-impairment wave; 2019+ registration reform (IPO supply, shell decay); 2024 国九条 delisting/dividend reform; add to the parent structural-break table.
7. **F-Score contract (v1.3):** annual source-faithful score becomes available only after the formal annual report fields exist. A 预告/快报 profit number cannot release CFO, current ratio, leverage or gross-margin components early. The quarterly, monthly-refreshed A-share specification in Jiang–Jin–Tang is a separate `FScore_CN_Q` research variant; never splice it into `FScore_P2000_Annual`.
8. **G-Score / expectation-error contract (v1.3):** map industry medians with PIT 申万 sectors and test source two-digit-SIC-style broad groups as robustness. Advertising and R&D disclosure are structurally sparse, and capex accounting is not identical to US data; `GScore_M2005_CN` remains **D** with component coverage reported by year/industry. The exact B/M 30/40/30 × annual-F-Score matrix is the source replication; 扣非 E/P, sector-relative value and quarterly F-Score are separately named local adaptations.
